## 📌 Overview & Upgrades

This modern portfolio replaces the classic legacy site with a sleek, interactive dashboard layout. Engineered for minimal manual maintenance, it dynamically fetches and displays real-time updates from across my digital ecosystem.

### 🔄 Key Improvements (Legacy ➔ New Portfolio)
* **📰 Automated Blog Sync:** Automatically pulls and displays featured posts live from [blog.baralaayush.com.np](https://blog.baralaayush.com.np).
* **💻 Automated Project Sync:** Dynamically feeds latest projects and web applications directly from [project.baralaayush.com.np](https://project.baralaayush.com.np).
* **⚡ Modern Tech Stack:** Rewritten from static assets to a reactive **TypeScript + React 18 + Vite** architecture.
* **🎨 Refined UI/UX:** Styled using modern Tailwind CSS for a fluid, mobile-first responsive layout.

---

## ✨ Features

* ** dynamic Content Feeds:** Seamlessly integrates external RSS/API data to keep project and blog feeds up to date.
* **📱 Fully Responsive:** Adaptive layout optimized across desktop, tablet, and mobile browsers.
* **🚀 Rapid Performance:** Lightning-fast page loads and instant module bundling powered by Vite.

---

## 🛠️ Tech Stack & Dependencies

* **Frontend:** React.js, TypeScript
* **Styling:** Tailwind CSS
* **Build Tooling:** Vite (`vite.config.ts`)
* **Package Management:** Bun / npm (`bun.lock`, `package.json`)
